# Netlify free plan until the first paying Shop

The MVP is hosted on Netlify's credit-based Free plan, not the paid plan the third-party spec first called for, so hosting costs nothing while no Shop is paying. We accept two risks. First, Netlify pauses a Free site when its monthly credits run out, which would take every Shop's Queue offline until the next cycle. Second, the functions region may not be changeable on Free, leaving functions in US East, so every action pays trans-Pacific hops between Malaysian browsers and the Singapore database. Both are tolerable while Shops are pilots and the product earns nothing. We move to a paid Netlify plan when the first paying Shop goes live, or earlier if credit usage passes about 70% mid-month. Deploy Previews stay disabled, because password protection isn't available on Free and a public preview wired to real data would expose the Operator API.
